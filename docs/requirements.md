# SkillSwap Requirements

## Project Goal

SkillSwap is a platform where users exchange skills.


## Target Users

- students
-Professionals
-Freelancers



## MVP Features

- Signup
- Login
- Create Profiles
- Add Skills
- Browse Users
- Search Users
- Send Swap Request
- Accept/Reject Request

## Non - functional Requirements

- Responsive
- Secure
- Fast
- Easy to use
